## What I do

Since 2021 I've worked as a software developer for IoT and industrial software at SHS plus. I build web applications that collect, process and visualize production data. Apart from my latest work in plastics manufacturing, where I use state-of-the-art technologies to build web apps, I also work with other tools in areas like machine learning and DSP. You can find more details in [my projects](/projects).

I like the whole path from first sketch to running software: drawing the mockups, building the frontend and backend, and actively supporting the users.

## How I got here

I studied Media Informatics at Rhine-Waal University of Applied Sciences with a special focus on UI/UX design. During my studies I worked as a working student, extending a C++ desktop application for industrial PLC systems and building websites for small businesses. For my bachelor's thesis at Daimler, I developed deep learning models that detect anomalies in acoustic data from transmission test benches.

## How I work

Having developed applications for several years before the AI era, I built a solid foundation in software architecture and development workflows. Today, I also make use of AI coding tools, but inside clear guardrails: written rules, tests and hooks that block shortcuts and secure integrity. This portfolio, for example, is built that way, as you can see in its [repository](https://github.com/tilohk/portfolio).

More details about my work and skill set are in my [resume](/resume). If you'd like to work together, [get in touch](/contact).
